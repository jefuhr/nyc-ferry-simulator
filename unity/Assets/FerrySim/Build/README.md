# Player Builds

`FerrySim.Unity.Build.Editor` builds standalone candidates and packages offline data. See [Releasing](../../../../docs/releasing.md) for commands, platform checks, locking and installed-player smoke evidence.

The enabled player scene is `Harbor.unity` only. Slice fixtures remain in the repository. `PlayerBuild` writes `build-report.json` with exact built scenes, packed asset paths, size, timing, warnings and errors. The `-ferrysimBothScenesEvidence` switch builds the explicit S5 comparison variant without changing the shipping scene list.

`HarborPayload` reads the root array in `Editor/harbor-payload.json`, validates the source index, render indices and local URIs, then uses the existing core readers for shared depth, environment, traffic and runtime validation. All 28 traffic date folders are explicit, excluding their sibling `_sources/`. Surface parameters, landing audit and canonical runtime geoid files are included. The chart pack root, `data/processed/harbor/chart`, is validated by `ValidateChart`: the core reader's self-integrity and runtime-digest checks, then every packaged input the chart manifest records (the skyline index, each consumed `attributes.json.gz` sidecar and the runtime manifest) against the current repository files.

`PlayerPayloadBuildStep` resolves and validates the requested scenes before a build, packages the explicit harbor inventory plus files named by those scenes, and enriches `build-info.json` with schemas, source digests, roots, exclusions and scene identities. The release verifier compares intended files against source bytes, copies and the build record, and rejects unrecorded data or slice dependencies in a shipping candidate.

The general `PlayerPayload` scanner stays available for slice regression builds. It discovers serialized `*File`/`*Files` and `*Folder`/`*Folders` fields in scenes and their referenced project assets, with existing containment and dependency restrictions. Its existing fixture tests remain unchanged.

`InstalledPathTests` covers packaged files/folders and unchanged missing-path fallbacks, and `PlayerShaderDependenciesTests` requires explicit player dependencies for runtime navigation shader lookups. `HarborPayloadTests` covers missing roots, forbidden intermediates/dot files, escaping URI, stale index hash, duplicate roots, scene selection and copied real-data preflight, plus the chart preflight: the chart root configured, a missing or stale chart pack refused, and a chart built against another skyline index, a changed sidecar or a changed runtime manifest refused by name. `Harbor/Player/Tests` covers startup selection, installed-path containment and a calibrated allocation-free drive poll. `Tests/test_release_tools.py` covers the independent release verifier and Windows recorder.
