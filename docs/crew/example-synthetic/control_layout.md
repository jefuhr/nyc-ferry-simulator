# Control layout (SYNTHETIC example)

Everything here is invented to show the format. No real wheelhouse was observed.

## Engine control heads (C1, C2, C5, C6, C7)

- Make and model: SYNTHETIC "example electronic control head", one lever per engine at the main station.
- Stations: main helm and one port wing station; transfer by a station-select button with the levers matched at neutral.
- Warm-up mode: yes, with the levers in neutral.
- Sync mode: fitted, not used.
- Docking joystick: none.

## Steering (S4, S5)

- Wheel; rudder angle indicator shows one rudder.
- Autopilot: none.
