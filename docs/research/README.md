## Recommended next sources


Request public vessel-specific builder trial summaries, equipment manuals, hydrostatic particulars and current registration/inspection data. Follow [the capture questions](crew-questions.md) for permitted observations; do not collect operator-internal documents, security information or personal data for this repository. For world construction, request public surveyed landing geometry and reproducible NOAA prediction requests. For AIS analysis, verify vessel identity first and distinguish speed over ground from an inferred water-relative response.


## Evidence policy


Confidence is provenance, not verification: high for operator, designer, builder and government; medium for trade/industry reporting; low for unofficial indexes. A readable source must support the retained statement. Derived estimates must show formula, sourced or estimated inputs, and result; D01 and D02 are arithmetic examples, not physics acceptance bands. Keep disagreements open until a separately read resolving source supports closure. Preserve source-attributed values rather than silently repairing them.
